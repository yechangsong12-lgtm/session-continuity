# 会话分工与交接

简体中文 · [English](../SKILL.md)

默认在原对话把事情做完。只有下面列出的情形，才考虑在**同一个助手**里开新的可见对话。用户中途追加的相容要求一并保留，交接时沿用用户的语言。

## 怎么判断要不要开新对话

| 遇到什么情况 | 怎么处理 |
| --- | --- |
| 仍在推进同一目标，包括继续执行、补充要求、修改或核对已有结果 | 留在原对话，沿用已有信息和决定。 |
| 一部分工作可以独立完成，主任务只需要它的结果 | 可交给后台子代理，完成后把结论、来源和明细位置交回主对话。 |
| 出现了有独立结果的旁支，后续需要用户持续跟进，同时主任务还能继续 | 建议另开旁支对话。先说明分出去的范围和理由，再确认是否开聊、用哪个模型。 |
| 上下文达到 80%，主任务仍有未完成工作 | 先按偏好存档并复核实际用量。空间够就原地继续；仍需整体接续时，再问是否开新对话。 |

**选模型。** 让用户从当前账号对这项任务实际提供的模型中指定，或明确委托 Agent 代选。后台子代理与可见对话分别看各自的可用列表。有适用的长期偏好就沿用；获准代选时，选能胜任且成本较低的模型并说清选了哪个。

## 存档与接手

1. 当前对话用量达到**实测有效窗口的 80%** 时，按偏好提醒或自动存档。压缩后重新看用量；若已有充足空间，或只剩一个小改动，就在原处继续。拿不到可靠读数时，可在阶段结束时建议存档。
2. 交接写清目标、用户修正、已做的决定与理由、已核对的证据位置、待办和可立即执行的第一步。省去凭据和带授权参数的链接。本地任务在技能目录依次运行以下命令，始终使用同一工作区及可选的 `--target`：

   ```text
   python scripts/checkpoint.py --root WORKSPACE --active-goal "当前目标" --context-file "证据文件路径" --open-task "下一步操作"
   python scripts/validate.py --root WORKSPACE
   python scripts/bootstrap.py --root WORKSPACE
   ```

   可读摘要在 `.agent/continuity/handoff.md`。如果只能传聊天文字，把摘要和必要证据交给**同一助手的新对话**，注明接手方能核实哪些内容。
3. 达到 80% 且确需整项迁移时，先核对来源模型及新对话的可用模型，再问：“是否沿用当前的 X 模型开接续对话？也可以换模型，或留在这里。”同意后复核用量与模型，再创建；已有接手对话时沿用已有记录。
4. 新对话核对修订号、回查第一项待办的一处原始证据，再报告下一步。主对话收到这份确认，才算接手完成。

## 该归档哪个对话

普通旁支先交回结果。等**主任务和子任务都完成**，证据已合入主对话、没有待办或待审、用户也没有要求保留，才整理**子对话**。用户已授权自动清理时可按该子对话的 ID 归档；否则问是否归档它。

只有整项迁移后，才考虑**原对话**。确认新对话已接手，再复核来源仍达到阈值且已无剩余工作，才问是否归档原对话。归档原对话需要用户明确同意。
